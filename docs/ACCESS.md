# Dashboard access

This instance has not been installed on the target WSL2 machine yet. After installation,
the default address is **http://localhost:8765**. The installer replaces this file with
machine-specific instructions, including service names and operating commands.

Start with the [Codex installation prompt](IMPLEMENTATION_PROMPT.md) or the
[manual installation guide](INSTALL_WSL2.md). The localhost address refers to your computer
after installation; GitHub does not host the dashboard.

For a separate project such as `AI_AGENT_OS_1`, follow the [instance guide](REUSE.md)
first, then run the installer inside the new instance folder.
