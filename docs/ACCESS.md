# Acesso ao dashboard

Esta instância ainda não foi instalada no seu WSL2. Depois da instalação, a porta padrão será
**http://localhost:8765**. Este arquivo será substituído por instruções específicas da máquina,
com os nomes dos serviços e comandos de operação.

Comece pelo [prompt de instalação para o Codex](IMPLEMENTATION_PROMPT.md) ou pela
[instalação manual](INSTALL_WSL2.md). O endereço localhost se refere ao seu computador depois
da instalação; não é um site hospedado pelo GitHub.
