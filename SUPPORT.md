# Support

AI Agent OS is an open-source project in active alpha development. Support is provided on a best-effort basis through the repository.

## Before opening an issue

1. Read the [README](README.md) and relevant documentation under [`docs/`](docs/).
2. Search existing issues to avoid duplicates.
3. Confirm the problem against the latest supported code on the default branch when practical.
4. Run the documented validation checks and keep any diagnostic information sanitized.

## Bugs

Use the repository's bug-report form and include the affected version or commit, reproduction steps, expected behaviour, actual behaviour and the smallest useful sanitized error details.

## Feature proposals

Use the feature-proposal form. Describe the problem and desired outcome first; implementation suggestions are welcome but are not required.

## Security

Do not use a public issue for vulnerabilities, credentials, tokens, authentication logs or other sensitive material. Follow [SECURITY.md](SECURITY.md).

## Scope

There is no guaranteed response time or commercial support SLA. Requests may be closed when they are outside project scope, cannot be reproduced, or are better addressed in the documentation.
