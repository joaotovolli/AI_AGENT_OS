## 0.2.0 — 2026-09-13

### Added

- Authorized GitHub operator follow-ups with durable handling.
- Compact per-goal diagnostic history.
- Optional diagnostic-advisor escalation while retaining the configured worker model.
- Framework provenance and validated update integration for existing instances.
- Separation between the Agent OS control surface and generated project interfaces.

### Validation

- Regression and integration coverage across Python 3.11, 3.12 and 3.13.
- Chromium dashboard workflows covering desktop and mobile viewports.
