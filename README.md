# AI Agent OS

A reusable, self-hosted Codex execution supervisor for WSL2.

## Initial delivery

Implementation in progress: persistent goals, a local dashboard, configurable Codex models and reasoning, GitHub checkpoints, automated readiness checks, and hourly maintenance. Runtime installation and authenticated Codex validation take place on the target WSL2 machine.

This repository is the source of truth for code, operating instructions, and sanitized progress. Credentials and private runtime logs remain on the local machine.
